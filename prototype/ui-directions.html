KN_JAVA_COLLECTION · 集合与统计口径

为什么平均分会算错：分子分母必须同源

你提交的 (90+60)/3 = 50.0 不算错，只是统计口径不对。理解这一节，缺考与空值的处理就过关了。

核心结论
平均分 = 有效成绩之和 ÷ 有效成绩个数。缺考（null）必须先从分子排除，也要从分母排除。分子分母必须来自同一个有效集合，否则口径不一致，结果不可比。
两种口径对照
口径公式结果
含缺考（分母含 null）(90 + 60) / 350.0 ✗
排除缺考（同源）(90 + 60) / 275.0 ✓
最小实现
// 过滤 null 后，分子分母来自同一集合
List<Double> valid = scores.stream()
    .filter(Objects::nonNull)
    .toList();
double avg = valid.stream().mapToDouble(v -> v).average()
    .orElse(0.0);
常见误区
把 null 直接当 0 参与计算——两者业务含义不同；或只过滤分子、不过滤分母，导致平均分被"摊薄"。
