# Role Capability Graph for LearnFlow

This is the first official `learnflow.plugin-package.v1` bundle. It turns
project-owned, version-pinned sources and explicit task seeds into an immutable
role capability snapshot. The snapshot is domain supply: reading, generating or
iterating it never changes LearnFlow's five-kernel learner state.

The executable runner speaks JSON-RPC 2.0 over stdin/stdout and receives no ORM
object, database address, account token or model secret. Any source or model
access must use a declared and project-authorized Host Port.

The bundle is distributed under the repository license. `signature.json` is
generated by the deterministic package build after all files are finalized.
