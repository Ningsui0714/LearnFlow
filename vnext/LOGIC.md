# LearnFlow vNext 逻辑书 · v0.1

> 一分钟版本：这是当前产品的全部逻辑。想改产品，先改这页。

## 产品

LearnFlow 是一个持续陪伴学生学习的对话空间。

当前只保留两个页面：

1. **Chat**：学生和 Tutor 持续讨论学习问题。
2. **设置**：配置模型连接与最基本的产品偏好。

## 对象

| 对象 | 只负责什么 |
|---|---|
| Conversation | 保存一段独立、可继续的对话 |
| Page Tab | 让多个对话和设置页同时打开、切换、关闭 |
| Settings | 保存模型地址和模型名称；API Key 不落本地存储 |

## 当前流程

```text
打开 LearnFlow
→ 新建或继续一个对话
→ 可以同时打开多个对话
→ 可以打开设置而不丢失对话现场
→ 刷新后恢复已打开页面
```

## 现在明确不做

- 不创建学习任务。
- 不创建项目。
- 不判断掌握程度。
- 不写五核记忆。
- 不接入旧 LearnFlow 的 Agent、Skill 或工作流。
- 不用占位内容假装模型已经回复。

## 后续增加功能的规则

1. 一个新对象必须能用一句话说明职责，否则不加。
2. 同一种状态只能有一个权威来源。
3. 页面只是视图，不能自己决定学习状态。
4. 先走通一个真实用户流程，再增加新的页面和 Agent。
