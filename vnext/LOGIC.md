# LearnFlow vNext 逻辑书 · v0.2

> 一分钟版本：这是当前产品的全部逻辑。想改产品，先改这页。

## 产品

LearnFlow 是一个持续陪伴学生学习的对话空间。

当前只保留两个页面：

1. **Chat**：学生和 Tutor 持续讨论学习问题。
2. **设置**：配置模型连接与最基本的产品偏好。

## 对象

| 对象 | 只负责什么 |
|---|---|
| Conversation | 保存一段独立、可继续、可确认删除的对话 |
| Page Tab | 让多个对话和设置页同时打开、切换、关闭；其中一个可作为并排副页 |
| Settings | 浏览器保存模型地址和名称；本地服务只从 `vnext/.env.local` 读取 API Key |
| Tutor State | 只决定当前或下一轮对话怎样回应 |

## 两种状态

| 状态 | 行为 |
|---|---|
| 自由态 | 默认状态；自然讨论、回答、澄清，不擅自创建学习任务 |
| 简单讲解态 | 先给必要解释，再按需给核心机制、最小例子和一个自检问题；一轮后回到自由态 |

学生可以手动指定下一轮。自由态识别到“什么是 / 讲讲 / 解释”等明确请求时，也会自动将该轮交给简单讲解态。简单讲解不能只用追问代替开场解释。

## 当前流程

```text
打开 LearnFlow
→ 新建或继续一个对话
→ 默认进入自由态
→ 普通消息由自由态回应
→ 解释请求进入一轮简单讲解，再回到自由态
→ 可以同时打开多个对话
→ 任一其他已打开页可以与当前页并排
→ 可以打开设置而不丢失对话现场
→ 刷新后恢复已打开页面
```

删除对话必须先确认；确认后同时删除该对话及其页签。删到最后一条时自动创建一个空白对话。

模型请求固定经过本地 `/api/tutor`。API Key 不进入页面、不写 `localStorage`，修改 `.env.local` 后重启服务生效。

对话正文按 Markdown、GFM 和 LaTeX 数学公式渲染；原始 HTML 不执行。

## 现在明确不做

- 不创建学习任务。
- 不创建项目。
- 不判断掌握程度。
- 不写五核记忆。
- 不接入旧 LearnFlow 的 Agent、Skill 或工作流。
- 不用占位内容假装模型已经回复。

## 后续增加功能的规则

1. 一个新对象必须能用一句话说明职责，否则不加。
2. 同一种状态只能有一个权威来源。
3. 页面只是视图，不能自己决定学习状态。
4. 先走通一个真实用户流程，再增加新的页面和 Agent。
