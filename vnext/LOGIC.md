# LearnFlow vNext 逻辑书 · v0.9

> 一分钟版本：这是当前产品的全部逻辑。想改产品，先改这页。

## 产品

LearnFlow 是一个持续陪伴学生学习的对话空间。

当前只保留两个页面：

1. **Chat**：学生和 Tutor 持续讨论学习问题。
2. **设置**：配置模型连接与最基本的产品偏好。

## 对象

| 对象 | 只负责什么 |
|---|---|
| Conversation | 保存一段独立、可继续、可确认删除的对话 |
| Page Tab | 让多个对话和设置页同时打开、切换、关闭；其中一个可作为并排副页 |
| Settings | 浏览器保存模型地址和名称；本地服务只从 `vnext/.env.local` 读取 API Key |
| Tutor State | 只决定当前或下一轮对话怎样回应 |
| Tutor Substate | 展示当前 Skill 正在怎样带领学习；它就是当前 Skill 步骤的对话投影，不另存第二套状态 |
| Tool Run | 保存一次搜索、图解或动画调用的状态、耗时、来源与产物；不判断掌握 |
| Follow-up Sheet | 保存一段选中文字和围绕它展开的分支对话；继承父页上下文，不复制用户画像 |
| Learning Task | 当前对话里的一个原子学习目标和暂停点；不规定通用教学流程，不代表掌握 |
| Learning Skill | 一种可选择的学习方法；拥有自己的步骤、分支、循环和支架规则 |
| Learning Plan | 对话内较大目标的可恢复规划草案；分为项目雏形与发展方向，不等于项目已经创建 |
| Value Claim Proposal | Tutor 根据学生明确表达提出的价值核修改候选；学生可接受、修改或拒绝，候选本身不写正式五核 |
| Profile Module / Claim | 一份只读、可检查的五核模拟画像；帮助选锚点和适配表达，不代表掌握 |

## 四种状态

| 状态 | 行为 |
|---|---|
| 自由态 | 默认状态；自然讨论、回答、澄清，不擅自创建学习任务 |
| 简单讲解态 | 先给必要解释，再按需给核心机制、最小例子和一个自检问题；一轮后回到自由态 |
| 带领学习态 | 围绕同一原子目标，在当前对话中组合 Skill、练习和检查；暂停或结束后回到自由态 |
| 学习规划态 | 处理跨多个任务、较复杂产物或未来方向；形成项目启动雏形或发展建议，不自动创建项目或改写五核 |

学生可以手动指定下一轮。自由态识别到“什么是 / 讲讲 / 解释”等明确请求时，也会自动将该轮交给简单讲解态。简单讲解不能只用追问代替开场解释。

当前四个 Learning Skill 都只绑定**带领学习态**。学生可在输入栏直接选择 Skill；尚无任务时，选择会把下一轮绑定为带领学习态，发送消息后才建立任务；任务运行中选择则从新 Skill 的第一步重新编排。Skill 的每一步同时声明一个子状态，例如“带领学习态 · 引导态 / 示范态 / 复述态 / 迁移态”。子状态只由同一条 Skill 事件队列投影，循环会留在当前子状态，不能由页面或模型自行跳转。

明确的“带我学 / 带我弄懂 / 带我练”会建立对话内任务。任务本身只保存目标、暂停状态和事件；清晰讲解、苏格拉底追问、费曼复述、示例渐隐各自拥有不同的步骤与循环。普通消息不自动推进；要求学生产出的步骤必须先收到一次回应，“不知道 / 要提示”和“再来一轮”会按当前 Skill 的支架规则留在本步并重新等待尝试。输入栏上方只显示一条任务锚点，完整 Skill 流程和运行记录收进选项菜单。所有判断掌握的能力仍未接入。

“系统学习 / 学习路线 / 几个月完成 / 做一个真实项目”和职业、科研、发展方向问题会进入学习规划态。项目雏形依次收集目标产物、当前基础、来源资源、时间投入、实践验收和现实约束；当前只形成可检查草案，“项目尚未接入”必须始终可见。发展规划先比较方向与低成本探索证据；只有学生明确表达长期倾向时才出现 Value Claim Proposal，并同时展示当前内容、建议内容、原话依据和影响范围。接受、修改、拒绝都进入本地零写入事件队列；在正式 EvidenceEvent/reducer 接入前，不更新 KernelState。

## 当前流程

```text
打开 LearnFlow
→ 新建或继续一个对话
→ 默认进入自由态
→ 普通消息由自由态回应
→ 解释请求进入一轮简单讲解，再回到自由态
→ 原子学习请求在当前对话进入带领学习态，并显示轻量任务控制条
→ 也可以先在输入栏选择学习方法，再用下一条消息建立该 Skill 的任务
→ 当前 Skill 步骤投影为“带领学习态 · 子状态”，随队列事件转换
→ 较大目标或发展方向进入学习规划态，在对话中形成规划草案
→ Value Claim 修改必须由学生查看依据后接受、修改或拒绝
→ 可以同时打开多个对话
→ 任一其他已打开页可以与当前页并排
→ 可以打开设置而不丢失对话现场
→ Tutor 按明确指令或自动识别调用搜索、图解、动画工具
→ 每轮 Tutor 先按当前问题、任务和 Skill 有界读取相关五核 Module/Claim
→ 回答先显示工具过程和来源/产物，再显示 Tutor 解释
→ 选中 Tutor 原文可新建一张追问纸，并在纸张间切换
→ 刷新后恢复已打开页面
```

删除对话必须先确认；确认后同时删除该对话及其页签。删到最后一条时自动创建一个空白对话。

模型请求固定经过本地 `/api/tutor`。API Key 不进入页面、不写 `localStorage`，修改 `.env.local` 后重启服务生效。

对话正文按 Markdown、GFM 和 LaTeX 数学公式渲染；原始 HTML 不执行。

搜索先识别讲解、对比、排错、实现、研究或最新变化，再围绕任务寻找互补证据。来源按“规范/官方文档 → 教材/大学课程 → 论文 → 社区实践 → 代码仓库”确定性重排；“什么是”默认覆盖定义、机制、最小例子和边界/误区。网页内容只作为不可信资料进入回答，搜索与讲解不写五核。完整约束见 `COMPUTER_KNOWLEDGE_SEARCH.md`。静态图只保存消毒后的 SVG；动画保存 3–9 个安全 SVG 步骤，由本地播放器切换，不运行模型生成的脚本。

当前五核画像是根据学习者明确自述建立的 vNext 模拟，只包含 Module 与 Claim。它是全局学习者对象，不属于某个 Session：最上方全局栏与左下角学习者卡片都可打开轻量摘要及五核 Module，设置页展示完整 Claim；Reader 不把整份画像塞给模型：讲解联取 Knowledge/Human/Structure，路径联取 Structure/Knowledge/Value，项目联取 Practice/Knowledge/Structure；敏感 Human Claim 只转成静默适配。它不写旧五核、不推断掌握，完整设计见 `FIVE_KERNEL_PROFILE_DESIGN.md`。

主对话是一张不可删除的纸。选中 Tutor 文字后创建子纸；子纸读取主对话、祖先纸和本页消息，但新消息只写本页。其他纸压在当前纸下，悬停纸边可横向展开并切换；第一次点击桌面空白会缩小平铺全部纸张，再次点击空白会按父子关系展开纸张树。任意追问纸均可单独删除，直接子纸会保留并上移一层。纸张不产生新的长期学习状态。

## 现在明确不做

- 不创建项目。
- 不判断掌握程度。
- 不写正式五核记忆；当前只有只读模拟 Module/Claim 与有界 Reader。
- 不把已接受的 Value Claim 候选伪装成正式写入；当前只保存学生决定，等待统一事件链接入。
- 不接入旧 LearnFlow 的后端任务、练习证据或学习状态工作流；只复用收紧后的四种 Skill 契约与零证据边界。
- 不用占位内容假装模型已经回复。

## 后续增加功能的规则

1. 一个新对象必须能用一句话说明职责，否则不加。
2. 同一种状态只能有一个权威来源。
3. 页面只是视图，不能自己决定学习状态。
4. 先走通一个真实用户流程，再增加新的页面和 Agent。
